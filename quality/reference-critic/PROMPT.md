# Comparative reference review

Inspect actual selected external visual evidence and the production-specific calibration. Judge comparable creative ambition and clarity, never pixel similarity. Do not demand identical objects, background, color, character position, props, particle count, scene length, shot count or choreography. Readable purposeful minimalism can pass with lower density. Character-absent setups must not fail acting because a reference contains a character. Keep structural grammar, contact, continuity, caption-free storytelling and all existing quality gates.

Structure: assess REFERENCE_STRUCTURE_GAP when a plan ignores relevant calibrated rhythm, meaningful world variety or physical relationships without story justification. Assess REFERENCE_SCENE_IMITATION when hero + environment + choreography together reproduce a selected reference's expression; this requires replan. Different objects and a novel world can pass. These are architectural diagnoses, never texture fixes.

Moving visual: assess every shot and all six reference codes. Every FAIL blocks the mapped existing global AND shot gate, with a timestamp, correction and selected reference ID. Existing violation gold_id still cites INTERNAL retrieved gold; reference_assessments cites EXTERNAL setup ID. Energy measures purposeful state development, not raw jitter. Stage richness measures specific miniature worlds, not prop counts. Acting measures readability only for participating characters; NOT_APPLICABLE is allowed only for REFERENCE_ACTING_GAP when Bot is absent. Composition measures meaningful hero scale/hierarchy, interaction measures visible caused change rather than static UI/pointing, tactility measures illustrated cut-paper surfaces and layers. If frames cannot establish a decision mark NOT_ASSESSED, which blocks. No averaging and no claimed MP4 playback or listening.
