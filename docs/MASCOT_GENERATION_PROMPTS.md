# Mascot concept prompt record

Mode: built-in `image_gen`, one generation per final direction, with `transparent_background: true`. The image reference was used to extract identity traits; selected still frames from the seven supplied videos were used for broad style cues. The output was required to avoid the source clips' characters, compositions, text and brand marks.

## Shared intent

> Create one original full-body Motif Bot as a matte, tactile, layered 2D paper cutout for a vertical explainer video. Preserve the supplied robot's off-white cream body, teal details, broad dark display, friendly teal expression, two leaf-like antennae, round side discs and `<>` coding badge. Redesign the silhouette from scratch. Keep it readable at phone size with simple flat shapes, slight fibrous texture and small down-right contact shadows. Deliver a genuinely transparent PNG. No glossy 3D material, armor detail, scenery, text, watermark or copied video assets.
