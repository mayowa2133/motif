# Motif structural grammar 1.0

Part of `motif-gold-v1`, above Quality System v1.1. The seven reference videos inform filmmaking relationships, not plots, characters, artwork or runtime inputs. Frozen VoiceStudio v6 remains a visual benchmark, not evidence for its narrated claims. The rejected reversible rowhouse is a negative example, never gold art.

**A setup persists while the same visual rule keeps evolving. A setup resets when the semantic rule changes.**

## Film → rhetorical chapters → setups → beats → motion layers

The film is an argument. Chapters mark changes of rhetorical purpose: hook, mechanism, proof/comparison, implication/limit, payoff/CTA are examples, not compulsory labels. A setup is a miniature world governed by one semantic rule. A beat changes a meaningful state inside that world. Do not flatten these levels into generic shots.

Extract propositions and semantic verbs (inspect, compare, select, burden, route, transform, restore…). Group adjacent propositions sharing a visual rule, then invent a suitable world. Arena attacks, counters and elimination can develop one contest. A backlog can develop through arrivals, fixes and count changes. House + checkpoint machine + diff machine + test tank + archive + rollback machine stretches one metaphor across unrelated systems: split it.

Relationship archetypes include physical interaction, interface stage, transformation, process, comparison, burden/accumulation, inspection, handoff, tournament/elimination, race, scan/count, test, target, gate/permission, callback, pile/cost, route/pipeline, staircase/order, archive/history and restore. These are reasoning aids, not scene templates. Do not repeatedly choose arena, washing machine, staircase, race, VoiceStudio or a bug board because a reference used one.

## Persistence, replacement and reset

Keep a long setup when its state continues to develop under the same rule. New state should replace, transform, remove, compress or exit old state. Accumulation is valid when it expresses cost, workload, instruction burden, candidates or findings. Do not retain unrelated mechanisms merely because they exist.

Continuity comes from meaningful tokens (file, receipt pile, sample, selected candidate, before snapshot), not the entire previous set. Record identity, origin/state, ordered usage, state changes and destination. One or two important tokens is a useful tendency, not a limit; justify every token. More than two nearly identical consecutive compositions for unrelated propositions needs a story reason. Compare hero/Bot placement, dominant silhouette, environment and camera scale. Random drift does not cure stagnation.

Hard cuts are the default when semantic rules or evidence classes change. Object-led transitions, lateral pushes and matched movement may connect related setups. A reset can change set, hero, framing, Bot role, interface layout or palette while preserving the same artist: identity, paper grammar, typography, shadows, motion and captions.

Reference-derived observations supplied in the analysis: approximately 90 setups in 225 seconds, mean around 2.5 seconds and median around 2.1; many 1.5–3.5-second setups. Dense passages often develop new state around 0.4–0.8 seconds. These describe references, not verified runtime metrics or production quotas. Never enforce exact setup/shot counts, durations, beat intervals, reaction counts, Bot presence, camera moves, particles, color changes or resets every sentence.

## Hierarchy and physical energy

At an active beat identify the dominant action, optional support, caused local reactions, residual motion and optional next-action overlap. Many objects can constitute one semantic group: twenty receipts can mean rising cost. Three unrelated large active groups warrant semantic/hierarchy review, not an SVG-node count rule. One primary active region and an optional secondary region is guidance, not arithmetic. Small residual movement does not create another hero region.

Physical actions commonly use anticipation → action → contact/transformation → reaction → residual motion. Starting ranges at 30fps: anticipation 2–6 frames, decisive action 5–15, contact/overshoot 2–8, reaction 4–12, residual 6–18. Vary by action; heavy impact, typing, paper flutter and recoil should differ. Next action may start before secondary motion settles, after the current causal result is understandable. Do not overlap unrelated hero ideas.

Keep v1.1 reaction radius, relevance/distance falloff and attached prop/contact transforms. Reactions affect the contacted object, performer, nearest relevant prop and event-specific accent as appropriate. No global shake, mandatory jitter or enrolling every nearby prop. Effects, camera motion and labels cannot replace a visible state change.

## Bot, interface and art direction

Choose exactly one Bot role per setup: participant, reactor, presenter or absent. Absence is valid when no causal/orientation role is needed. At 360×640, silhouette first, face second. Retain supported talking, listening, focused, anticipating, impact-light/heavy, worried, burdened, surprised, relieved, celebrating, climbing and typing states. Act through supported head/eyes/mouth/torso/arms/hands/antennae/feet; do not redesign anatomy, realistic fingers or humanoid elbow/knee machinery.

For software, first ask whether the interface can be the physical stage: buttons depress under Bot, menus become climbable, files enter slots, outputs emerge, cards move states, progress mechanisms advance. A screenshot behind a tiny pointing mascot is weak evidence. Do not force an unrelated metaphor when physical interface relationships communicate better.

Use theatrical paper sets, usually two or three useful location cues. Justified minimal-isolated scenes remain valid under v1.1. Shallow depth uses background/midground/action/foreground, overlap, contact shadow, layered paper, relative scale and optional foreground crop; no realistic room requirement or mandatory clutter. Designed irregularity (off-axis tags, unequal receipts, staggered tabs, asymmetric stacks, partial crops) must serve story, location, action or balance. Avoid random rotation, distortion, grain escalation or jitter.

Cream/teal/dark display preserve identity. Approved support families (coral, marigold, slate, plum, deep teal, warm paper) can signal a purposeful new idea/set. Do not randomly recolor every second. Keep the default style; expressive presets remain explicit choices.

## Information channels and evidence

Top headline supplies editorial context; central action explains; bottom physical paper caption chunks follow speech rhythm; local UI labels identify only necessary states. Avoid four copies of the same sentence. Captions normally use natural 1–5-word groups, progressive arrivals, slightly independent paper rotations and stable letters. Do not obscure hero contacts, shake letters, use generic wide subtitle bars or reset captions solely because a cut occurs. Align to actual narration.

Tiny UI can be texture only when nonessential. Enlarge/isolate the actual focal detail (gap, counter, button, route, mark, connection), not just its container. Condition → visible result → confirmation label. PASS/FAIL/DONE/BEST/SELECTED/VERIFIED must follow evidence. Caption-free native viewing must still communicate the central action.

A qualitative glance test at 360×640 asks “what is the main thing happening?” No millisecond metric. Dense but legible; energetic but hierarchical; playful but causal; handmade but controlled.

Reference audio analysis reported roughly 4.9–6.8 onsets/second including speech, commonly 0.14–0.16-second gaps. This is qualitative rhythm evidence, not an SFX quota. Coordinate speech emphasis, captions, contact, UI and effects; it does not authorize audio finishing in this task.

## Executable workflow

1. Split rhetorical propositions and assign semantic verbs.
2. Group shared rules into setup candidates; split unrelated mechanisms.
3. Choose relationship, original hero/set, Bot role and meaningful tokens.
4. Record `film_structure` before detailing beat-level v1.1 contracts.
5. Run the separate data-only structure critic. Any failure/unassessed check means **REPLAN_REQUIRED**.
6. Run existing direction/art review only after a fresh structure PASS.
7. Compile and render moving rough; story/visual critics retain all ten gates and add hierarchy diagnoses.
8. Apply bounded meaningful repairs; no final art until gates pass. Final picture QA, technical checks, audio and human approval retain their existing boundaries.

Word spans are zero-based half-open indices in whitespace-split narration. Chapters/setups cover the entire script in order; `beat_ids` assigns each ordered beat once. Setup role/environment agree with existing contracts. No duplicate per-beat setup fields or renderer changes. Stored legacy contracts can still be validated without rewriting; new direction/rough entry points require structure. Unsupported worlds remain explicit agent-assisted capability needs, not falsely executable plans.

Structure checks: METAPHOR_OVERLOAD, STATE_ACCUMULATION_WITHOUT_MEANING, SEMANTIC_GROUP_OVERLOAD, COMPOSITIONAL_STAGNATION, CONTINUITY_TOKEN_OVERLOAD, CLUTTER_WITHOUT_PURPOSE, WEAK_RESET_RHYTHM; planned COMPETING_FOCI and CAPTION_CARRIES_STORY also block. The critic judges the sequence, not artwork. Moving hierarchy codes map into existing gates (see `quality/rubric/hierarchy.json`), never average away failures.

This implementation validates internal planning fixtures only. It does not approve an original film or replan the rejected production. Preserve its evidence. The next production task starts from its exact script with no manually supplied shot list.
