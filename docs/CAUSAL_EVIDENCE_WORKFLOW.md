# Production scope and causal evidence

This workflow extends the Gold gate and PR #8 registry. It does not approve an artistic method. Existing production files are preserved; resuming a historical project requires an explicit scope declaration, never an inferred legacy bypass.

New direct, supplied-script and news runners declare `original-film`. The old calendar template declares `technical-fixture` and reports `SCOPED_OUTPUT_ONLY`. Reference-informed, faithful-editable and raster-animatic are separate explicit modes; substitution is rejected. Declare a saved project's requested mode with `python scripts/motif_evidence.py declare --project PATH --mode MODE`. A film requires its existing `motif-gold-v1` plan. Library compilers also reject omitted quality mode unless the caller explicitly declares a technical fixture.

Before capturing a scoped film, supply `causal-map.json` and `critical-intervals.json`. Missing inputs stop before rendering. Each proposition quotes an exact half-open word range from the saved script, identifies its shot, external initiator/stimulus, action, before/after state, persistent result, diagnostic feature, stimulus/action frame and inclusive review interval through `persistent_until_frame`. Every shot needs an evidence route. Each critical interval is inclusive and must cover its frozen proposition interval. A plausible mapping is data validation, not independent proof that the pictures communicate it. Unresolved data needs authored completion before capture; the runner does not invent a cause to satisfy a field.

Example proposition fields: `id`, `shot_id`, `word_range: [0,3]`, `text: "Wait for input"`, `subject`, `initiator`, `stimulus`, `action`, `before`, `after`, `persistent_result`, `diagnostic_feature`, `stimulus_frame: 3`, `action_frame: 4`, `persistent_until_frame: 29`, `review_interval: [0,29]`, `claim: {"status":"illustrative"}`. Declare critical evidence with `[{"id":"wait","critical_intervals":[[0,29]]}]`. Supported claims additionally require attribution, date, excerpt and uncertainty; this does not independently fact-check them.

The sampler presents all declared critical frames in consecutive phone-size strips, plus existing context frames. It preserves coverage in the manifest and binds maps/scope to render-source freshness. Both caption modes must cover frozen requirements. Final delivery is sampled directly, including the 1080×1920 delivery path downsampled to 360×640; matching duration alone does not approve a different picture. Image critics still do not watch or listen.

`rough` freezes plan/event/scope/map/interval hashes before its first capture command, then seals the exact encoded artifacts. Manual final-picture capture uses `motif_evidence.py freeze-capture --project PATH` before commands and `seal-capture --project PATH --capture-record RETURNED_RECORD --artifacts CAPTIONS NO_CAPTIONS DELIVERY` afterward. Sampling and advancement require those same frozen inputs and artifacts; changing a map after capture cannot shrink the evidence requirement. Failed attempts remain recorded. UI shot bounds come from its actual saved frame schedule.

For scoped film technical checks, each supplemental check has its own hash-bound JSON source with `check`, `status`, `observation`, event/video hashes and `coverage: {"enabled":true,"required":N,"checked":N,"scope":"..."}`. Positive nonzero complete counts are required. The supplemental manifest carries identical values plus source `file`/`sha256`; normalization and final advancement revalidate its contents. Counts are producer evidence, not independent perception. An empty text inspection or disabled motion audit cannot obtain a PASS by labels alone.

`completion-evidence.json` records the exact encoded artifact and pending human dimensions; audio finishing is not full-film approval. `quality/causal-pilot/protocol.json` is a proposed protocol with effort/randomization fields deliberately unset. Freeze four actually unfamiliar paired scripts with `motif_causal.freeze_study` after filling those fields and exact component hashes. `playback_counts` only accepts five distinct attested first-exposure normal-speed records per arm; it never manufactures answers or infers AV from them. Real listening remains separate. Promotion/rollback uses `motif_experiment_gate`, including original and last-good comparisons. Ties and incomplete human evidence hold promotion.

Rollback: revert this implementation increment to its parent commit; preserve failed maps/reviews and current production archives. No artist or asset catalog is promoted by contract checks. Waiting-scene execution, contact/mobile checks and portability follow as a bounded optional compiler, not a universal scene schema.
